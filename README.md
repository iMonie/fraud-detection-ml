\# Fraud Detection Using Machine Learning



\## 📌 Project Description

This project uses Logistic Regression to detect fraudulent financial transactions using machine learning.



\## 🧠 Model Used

\- Logistic Regression (Binary Classification)



\## 📊 Features

\- Confusion Matrix

\- Classification Report

\- Accuracy Evaluation

\- Data Visualization (Matplotlib + Seaborn)



\## 📁 Dataset

A simple synthetic dataset containing transaction amounts and labels:

\- 0 = Legitimate transaction

\- 1 = Fraudulent transaction
